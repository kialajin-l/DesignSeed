Features
Everything you need for AI-native design generation
🎨
12 Built-in Styles
From Minimalism to Cyberpunk, Ink Wash to Memphis. Each style is a complete design system with colors, typography, layout, and component tokens.
🔬
Style Mixing
Blend any two styles to create hybrid aesthetics. The engine intelligently merges color palettes, typography scales, and layout parameters.
📄
design.md Format
A structured markdown format that captures design intent. Readable by both humans and AI agents, enabling seamless design-to-code workflows.
🌱
17 Seed Design Systems
Pre-built seed systems that serve as starting points. Each seed is a complete, production-ready design system that can be customized and evolved.
🧠
Embedded Memory
Design decisions are embedded as context, not just parameters. The system remembers why choices were made, enabling intelligent evolution.
⚖
Aesthetic Rules
Formality, warmth, complexity, innovation — each style carries tonal dimensions that guide AI agents in making consistent design decisions.

Quick Start
import { DesignSeed } from 'designseed';

// Generate a complete design system from a seed
const seed = new DesignSeed({ style: 'cyberpunk' });

// Mix two styles
const mixed = seed.mix('glassmorphism', { ratio: 0.6 });

// Export as design.md
await mixed.exportDesignMd('./design.md');

// Generate HTML preview
await mixed.generatePreview('./preview.html');
